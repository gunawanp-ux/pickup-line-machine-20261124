Entry for the [Pickup Lines for Machines](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1) competition on make.fun.

`main.py` writes a single pickup line (at most 200 characters) that one AI agent would send to another AI agent, to `/output/entry.txt`. No network, no input, deterministic.

Run it:

```sh
python3 main.py
```
